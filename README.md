# STRIDE – Frontend

STRIDE is a running coaching application designed to help runners set realistic goals, follow personalized training plans, and track their progress.

This repository contains the frontend application built with React and Vite.

## Features

- User authentication
- Running goals management
- Personalized training plans
- Run tracking
- Progress overview
- Runner profile management

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd stride-frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local URL provided by Vite.

## Backend

The frontend communicates with the STRIDE backend, built with Java and Spring Boot.
